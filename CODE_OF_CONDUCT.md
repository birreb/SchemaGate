# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be decent to people. Assume the other person is trying to help. Criticise the code
rather than the person who wrote it, and take the disagreement to the evidence where there is
any to be had.

Unacceptable behaviour includes harassment, personal attacks, publishing someone's private
information, and sustained disruption. Maintainers may edit, hide or delete contributions that
do not follow this, and may block accounts for repeated or serious breaches.

## Reporting

Report a problem by opening a
[private security advisory](https://github.com/birreb/SchemaGate/security/advisories/new),
which is the only private channel this repository has. Reports are handled confidentially.

The full text of the Contributor Covenant, including the enforcement guidelines this project
follows, is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
